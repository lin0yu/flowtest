# FlowTest NL · 需求说明书

> 纯命令行（CLI）自然语言 Web 自动化测试工具
> 版本：v1.0 ｜ 定位：面向公司项目的「上线前冒烟 / 交付验收」执行工具
> 形态：纯 Node.js 单体 CLI，**不含后端服务、不含前端界面、不落数据库**

---

## 1. 背景与目标

### 1.1 要解决的问题

在公司的 Web 项目上，测试场景的覆盖长期不足：

- 场景写得慢、改版后维护成本高，正向用例之外（异常、边界、权限）几乎没人写；
- 上线前靠人工点一遍，耗时且无法留痕复用；
- 自动化「写了但不敢信」——只能确认页面出现某句话，无法确认数据真的写对了。

### 1.2 目标

交付一个**打开终端就能用**的自动化测试执行工具：

```text
自然语言 → 自动编译为测试脚本 → 驱动本机 Chrome 执行 → 逐步断言并截图 → 生成可交付的 HTML 报告
```

使用者不需要理解前端代码、不需要搭环境、不需要维护数据库；用业务语言描述流程，工具负责执行、验证、出报告。

### 1.3 成功标准（验收口径）

| 维度 | 标准 |
| --- | --- |
| 上手成本 | 新同事 10 分钟内能写出一条并跑通的用例 |
| 场景覆盖 | 核心业务链路 100% 可用自然语言描述并执行 |
| 结果可信 | 报告能区分「用例失败」与「环境/定位问题」，失败可定位到具体元素与期望/实际值 |
| 交付形态 | 一台装了 Node 18+ 与 Chrome 的机器即可运行，无需 JDK、无需数据库、无需部署 |
| 批量能力 | 一次可跑几十条用例，输出汇总通过率与失败清单 |

## 3. 约束条件（决定方案走向）

| # | 约束 | 影响 |
| --- | --- | --- |
| C1 | **只要 CLI**：不要后端服务、不要 Web 界面 | 全部能力用命令行与本地文件承载；结果只写本地报告目录 |
| C2 | **不落数据**：不需要数据库、不需要用例管理后台 | 无需账号体系、项目/环境管理、任务调度 |
| C3 | **前端基本不能改造**（无法大规模埋 `data-testid`） | 定位必须以「可见文字 / placeholder / aria-label / 结构」为主，并具备多级降级与失败自诊断 |
| C4 | 主要用于**上线前冒烟与验收** | 报告要「可交付、可转发、可讲解」；执行要快、要稳、失败要好定位 |
| C5 | 运行环境为公司内网机器 | 依赖尽量少；默认离线可用，不依赖外部模型服务 |

## 4. 功能需求

### F1 自然语言用例（必须）

- 用中文描述流程，一行一个动作，编译为可执行步骤。
- 支持动作：打开、点击、输入、按键、选择下拉、悬停、勾选/取消、滚动、等待、等待元素出现/消失、上传文件、截图。
- 支持断言：页面文本、页面标题、当前地址、元素可见/隐藏、元素值、元素数量。
- 编译结果可预览（`compile` 命令），用于确认识别是否正确。
- 解析失败时给出明确提示（哪一行没识别、建议怎么写），不中断其他用例。

### F2 执行（必须）

- 驱动本机 Chrome 真实操作页面；每个用例独立浏览器上下文，互不污染。
- **隐式跑**（默认无头，不打扰）：适合 CI、发版前批量跑。
- **显示跑**（`--headed`）：适合开发调试，肉眼看着它点。
- 每步超时可控，超时按失败处理并保留现场。
- 相对地址基于 `--url` 拼接，支持绝对地址。

### F3 逐步验证与取证（必须）

- 每一步执行后立即判断对错：断言失败即该步失败，记录「期望值 / 实际值」。
- **每步截图**，失败步骤同样截图。
- 失败时额外留证：页面 DOM 快照、控制台错误、失败元素的可选定位候选（见 F5）。
- 一条用例中某步失败后，后续步骤标记为未执行，整条用例判失败。

### F4 报告（必须）

- 单用例 HTML 报告：概览（状态、通过率、耗时）、步骤明细表、每步截图、期望/实际值、失败定位信息。
- 截图既可引用同目录文件，也支持**内联进 HTML**（`--inline`），产出单文件报告便于转发。
- 批量汇总 `summary.html` + `summary.md`：通过率、失败清单、每例耗时、跳转链接。
- 报告样式适合直接发给同事或放进交付材料。

### F5 定位与容错（关键，因 C3 而必须强化）

前端无法埋点，因此定位要「多路可用 + 失败可诊断」：

1. **多级定位优先级**：`text=可见文字` → `placeholder=` → `aria-label` / `title` → `data-testid` → CSS → XPath。
2. **纯文字兜底**：未显式写选择器时，自动按可见文字查找（支持 button/a/任意元素、精确与包含两种匹配）。
3. **多候选与模糊匹配**：一个动作可写多个候选定位（如 `text=新增 | 新建 | 添加`），命中任一即算定位成功。
4. **失败自诊断**：定位失败时，输出当前页面上所有可见可交互元素（文字 + 标签 + 建议选择器），使用者可直接复制粘贴修正用例——这是前端不能改时最有效的自愈手段。
5. **表格/重复元素**：支持按行关键字定位行内按钮（如「张三」这一行的「编辑」），避免同名元素点错。

### F6 批量执行（必须）

- 扫描目录批量执行 `.nl/.txt/.md` 用例；并发数可配。
- 单条失败不中断整体；失败可按次数自动重试。
- 汇总通过率、失败清单、耗时；退出码：全部通过 `0`，任一失败 `1`。

### F7 变量与数据（必须）

- 用例中用 `${变量}` 引用运行时注入的账号、密码、项目名、测试数据。
- 注入方式：`--var k=v`（可多次）或 `--env-file vars.json`；也支持直接读同名环境变量。
- 敏感变量（密码/token）在报告中默认不展开明文。

### F8 登录态复用（应当）

- 一次登录、多条用例复用（storage state），避免每条都走 SSO 登录，显著缩短总时长。
- 登录态失效时给出明确提示并可自动重新登录。

### F9 参数化与数据集（应当）

- 同一份用例配多组数据（CSV/JSON）批量执行，报告按数据组区分。
- 用于覆盖不同角色、不同测试账号、不同边界输入。

### F10 断言维度扩展（应当）

- UI 断言（已有）
- 接口断言：捕获执行过程中的网络请求，校验状态码/业务字段
- 文件断言：上传后校验文件名/大小，下载后校验存在与大小
- 属性断言：校验元素属性、class、input value

### F11 失败取证（应当）

- 失败自动保存：截图、DOM 快照、控制台日志、失败步骤前后的网络请求摘要。

### F12 CI 集成（应当）

- 输出 JUnit XML，可直接被 Jenkins/GitLab/GitHub Actions 识别。
- 退出码语义稳定；失败分类（用例失败 / 环境问题 / 定位失效）。

## 5. 非功能需求

| 项 | 要求 |
| --- | --- |
| 依赖 | Node 18+、本机 Google Chrome；不依赖 JDK、不依赖数据库、不依赖外网（LLM 编译为可选增强） |
| 性能 | 单条 10 步用例约 5s（含浏览器启动）；批量并发 3 时，20 条约 1 分钟内完成 |
| 稳定性 | 单步超时默认 10s 可配；失败重试；同一用例重复执行结果稳定 |
| 安全 | 密码等敏感变量不入报告；报告目录本地保存；不上传任何数据到外部服务（除非显式启用） |
| 可移植 | macOS / Linux / Windows 可用 |

## 6. 交付形态

```text
nltest/
├── index.mjs            CLI 入口
├── lib/
│   ├── compiler.mjs     自然语言 → 步骤
│   ├── runner.mjs       Chrome 执行 / 断言 / 截图
│   └── report.mjs       HTML / Markdown 报告
├── examples/            示例用例（单条 + 批量）
└── README.md
```

运行方式：

```bash
npm install                                  # 一次性安装依赖
node index.mjs run --file 用例.nl --url ...  # 单条
node index.mjs run-all --dir ./cases        # 批量
node index.mjs compile --file 用例.nl       # 只看编译结果
```

- [ ] 批量执行 20+ 用例，输出汇总报告，任一失败退出码为 1

## 8. 明确不做（本版本范围外）

## 10. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 前端不配合埋点，元素定位脆弱 | 用例易失效 | F5 多级定位 + 失败自诊断 + 用例集中维护 |
| 验证码/短信/双因素登录 | 无法自动化登录 | 申请测试账号、测试环境关闭验证码、或改为登录态复用 |
| 测试数据互相污染 | 结果不可信 | 参数化数据 + 造数/清理接口（需公司提供） |
| 断言只看页面文字 | 假通过 | F10 增加接口/数据维度断言 |
| 无覆盖视图 | 不知道缺什么 | M3 覆盖矩阵报告（功能点 × 角色 × 正/异常） |
